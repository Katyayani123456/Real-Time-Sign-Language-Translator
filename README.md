# Real-Time Sign Language Translator

## 📌 Overview

A Machine Learning and Computer Vision project that recognizes hand gestures in real time using a webcam and translates them into text.

## 🚀 Technologies

- Python
- OpenCV
- MediaPipe
- Scikit-learn
- NumPy
- Jupyter Notebook
- Git & GitHub
